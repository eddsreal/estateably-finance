# Quickstart & validation: UI redesign

**Feature**: [spec.md](spec.md) | **Plan**: [plan.md](plan.md) | **Date**: 2026-09-23

Setup, environment and root scripts are unchanged from
[feature 001's quickstart](../001-personal-finance-manager/quickstart.md): `docker compose up`
(reviewer path), or `pnpm install`, `docker compose up postgres`,
`pnpm db:migrate && pnpm db:seed`, then `pnpm dev`. This feature adds no environment variable. `pnpm install` picks up the two Tailwind devDependencies.
One script is new: `pnpm --filter web run check:tokens`, which is also run in CI (research R-005).
